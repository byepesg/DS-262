# Snake Challenge - Quiz 03

**Versión de Java utilizada:** Java 16 (o superior), requerida obligatoriamente para el soporte nativo de la estructura inmutable `record` de la clase Position.

## Instrucciones de compilación y ejecución

1. Abrir una terminal de comandos y navegar hasta el directorio raíz del proyecto (donde se encuentra contenida la carpeta `src`).
2. Compilar todos los archivos `.java` ubicados en el directorio `src` ejecutando el siguiente comando:
   ```bash
   javac src/*.java
