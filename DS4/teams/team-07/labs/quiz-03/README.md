# Quiz-3-Estructuras-de-Datos
# Quiz 03 – Dynamic Arrays and Amortized Analysis

## Versión de Java

Java 16 o superior (se utilizan `record`).

## Compilación

Desde la raíz del proyecto (donde está la carpeta `src/`):

```bash
javac src/*.java
```

## Ejecución

```bash
java src.Main
```

Esto reproduce la traza de la Pregunta 3 (movimientos N1–N6 sobre `Snake`).
