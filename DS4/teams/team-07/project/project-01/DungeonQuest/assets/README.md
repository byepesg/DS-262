# Recursos gráficos

En esta primera entrega, Dungeon Quest utiliza las herramientas de dibujo integradas en Godot para representar las habitaciones, las conexiones y la posición del jugador.

Por esta razón, el prototipo no necesita imágenes, texturas ni archivos de audio externos.

## Organización de recursos

Si se incorporan recursos gráficos o sonoros en futuras versiones, se recomienda organizarlos de la siguiente manera:

- `sprites/`: imágenes de personajes, objetos y elementos decorativos.
- `textures/`: texturas utilizadas en los escenarios.
- `audio/`: música y efectos de sonido.
- `fonts/`: fuentes tipográficas adicionales.

## Consideraciones

Los recursos deben almacenarse dentro de esta carpeta para mantener organizado el proyecto y facilitar la colaboración entre los integrantes del equipo mediante GitHub.

Cualquier recurso externo incorporado posteriormente debe contar con una licencia que permita su uso en el proyecto.
