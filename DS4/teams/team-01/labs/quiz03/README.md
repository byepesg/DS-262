Requisitos y Ejecución
Versión de Java:
Java SE 17 (o superior)

Instrucciones de Compilación
Desde la raíz del proyecto, ejecute el siguiente comando en la terminal:

```bash


javac src/*.java -d bin/

```
Instrucciones de Ejecución
Para ejecutar la solución y reproducir la traza de la Pregunta 3:

```bash

java -cp bin Main

```
