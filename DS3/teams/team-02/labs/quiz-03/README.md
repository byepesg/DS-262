# Instrucciones

## Versión de Java

```
openjdk 21.0.12.1 2026-08-18
OpenJDK Runtime Environment (build 21.0.12.1+1-1-24.04.4-Ubuntu)
OpenJDK 64-Bit Server VM (build 21.0.12.1+1-1-24.04.4-Ubuntu, mixed mode, sharing)
```

## Compilar

Se requiere un JDK 16 o superior (que incluya `javac`). Desde la carpeta `quiz-03/`:

```bash
javac -d out src/DynamicArray.java src/Snake.java src/Position.java src/Main.java
```

## Ejecutar

Desde la carpeta `quiz-03/`:

```bash
java -cp out Main
```
