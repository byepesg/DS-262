
## Ejecutar código


Abre la consola de tu equipo en la ruta ~/Pandemic-main.
Para compilar el código ejecuta "javac -d bin src/estructurasDatos/*.java src/mundo/*.java src/mundo/cartas/*.java src/datosObjetos/*.java src/juego/*.java src/juego/mazo/*.java"
Para ejecutar la implementación, escribe "java -cp bin juego.Main".
Con esto el juego inicializará su ejecución

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies

Meanwhile, the compiled output files will be generated in the `bin` folder by default.
